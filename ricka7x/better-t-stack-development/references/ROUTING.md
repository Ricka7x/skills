# Web Routing (TanStack Router + oRPC)

## Setup

oRPC client and `queryClient` live in `apps/web/src/utils/orpc.ts` and are injected into the router context in `apps/web/src/main.tsx`. Access them anywhere via `Route.useRouteContext()`.

```ts
// apps/web/src/main.tsx
const router = createRouter({
  routeTree,
  defaultPreload: "intent",
  defaultPendingComponent: () => <Loader />,
  context: { orpc, queryClient },
  Wrap({ children }) {
    return <QueryClientProvider client={queryClient}>{children}</QueryClientProvider>;
  },
});
```

## Creating a New Route

**1. Create the file** in the appropriate group folder.

**2. Export `Route` with `createFileRoute`:**

```tsx
// apps/web/src/routes/(app)/dashboard/posts.tsx
import { createFileRoute } from "@tanstack/react-router";
import { useQuery } from "@tanstack/react-query";
import { orpc } from "@/utils/orpc";

export const Route = createFileRoute("/(app)/dashboard/posts")({
  component: PostsPage,
});

function PostsPage() {
  const { data, isPending } = useQuery(orpc.posts.list.queryOptions());

  if (isPending) return <div>Loading...</div>;

  return (
    <div>
      {data?.items.map((post) => <div key={post.id}>{post.title}</div>)}
    </div>
  );
}
```

**3. Rebuild the route tree** (happens automatically with `vite dev`):

The `routeTree.gen.ts` file is auto-generated by the TanStack Router Vite plugin — never edit it manually.

## Auth Guards

Protect routes using `beforeLoad`. The app layout route (`(app)/route.tsx`) handles the top-level auth check — individual protected routes inherit it.

```tsx
// apps/web/src/routes/(app)/route.tsx
import { createFileRoute, redirect, Outlet } from "@tanstack/react-router";
import { authClient } from "@/lib/auth-client";

export const Route = createFileRoute("/(app)")({
  component: AppLayout,
  beforeLoad: async () => {
    const session = await authClient.getSession();
    if (!session.data) {
      throw redirect({ to: "/login" });
    }
    return { session: session.data };
  },
});
```

**Admin guard:**
```tsx
beforeLoad: async ({ context }) => {
  const session = await authClient.getSession();
  if (!session.data) throw redirect({ to: "/login" });
  if (session.data.user.role !== "admin") throw redirect({ to: "/dashboard" });
  return { session: session.data };
},
```

**Key rules:**
- Always `throw redirect(...)` — not `return redirect(...)`
- Never use `navigate()` inside `beforeLoad`
- Return session from `beforeLoad` to make it available in route context

## Data Fetching

Always use `orpc.*` generated options — never manual `queryFn`:

```tsx
// ✅ Query (read)
const { data, isPending, isError } = useQuery(orpc.posts.list.queryOptions());

// ✅ Query with input
const { data } = useQuery(
  orpc.posts.get.queryOptions({ input: { id: postId } })
);

// ✅ Mutation (write)
const mutation = useMutation(orpc.posts.create.mutationOptions());
await mutation.mutateAsync({ title, content });

// ✅ Invalidate after mutation
queryClient.invalidateQueries({ queryKey: orpc.posts.list.key() });

// ✅ Prefetch on hover
onMouseEnter={() => {
  queryClient.prefetchQuery(orpc.posts.get.queryOptions({ input: { id } }));
}}
```

## Search Params

Validate search params with Zod:

```tsx
import { z } from "zod";

export const Route = createFileRoute("/(app)/dashboard/posts")({
  validateSearch: z.object({
    page: z.int().min(1).default(1),
    search: z.string().optional(),
    status: z.enum(["draft", "published"]).optional(),
  }),
  component: PostsPage,
});

function PostsPage() {
  const { page, search, status } = Route.useSearch();
  // search params are fully typed
}
```

Use `nuqs` for URL state that needs to sync with external navigation or be shareable.

## Route Loaders (Prefetch Pattern)

Prefetch data in route loaders so it's ready before the component renders:

```tsx
export const Route = createFileRoute("/(app)/dashboard/posts/$id")({
  loader: ({ params, context }) => {
    context.queryClient.ensureQueryData(
      context.orpc.posts.get.queryOptions({ input: { id: params.id } })
    );
  },
  component: PostDetailPage,
});
```

## Error Handling

Global query errors show a toast (configured in `utils/orpc.ts`). For local mutation errors:

```tsx
try {
  await mutation.mutateAsync(input);
  toast.success("Saved!");
} catch {
  toast.error("Failed to save");
}
```

## Anti-Patterns

- ❌ Use `navigate()` inside `beforeLoad` — use `throw redirect(...)`
- ❌ Return `redirect(...)` without `throw`
- ❌ Manual `queryFn` when an oRPC option exists
- ❌ Edit `routeTree.gen.ts` — it's auto-generated
- ❌ Skip `credentials: "include"` — already set in the oRPC `RPCLink` fetch config
- ❌ Define `queryClient` or `orpc` in component scope — use the singletons from `utils/orpc.ts`
- ❌ Omit query invalidation after mutations
